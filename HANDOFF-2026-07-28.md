## Coupling with the Ghost migration (ghost-pp repo)

Timeline there: content export to Ghost ~Aug 1–2, 30-day staging test Aug 17–Sep 15,
cutover ~Sep 16, **WordPress decommission after ~Sep 23**.

1. **Before WP decommission (~Sep 23): export the 260 existing TAC posts** from
   PowerPage WordPress (`wp export --post_type=post --category=the-apple-core`).
   Tracked in ghost-pp MIGRATION-CHECKLIST Phase 6 — much harder to do once
   Bluehost is gone. Those 260 also ride along in the main Ghost migration.
2. **Republishing recovered posts onto PowerPage happens post-cutover via the Ghost
   Admin API** — do NOT bulk-import into WordPress before the export window
   (deliberate decision: don't disturb the source of truth days before handoff).
3. Ghost-side representation when the time comes:
   - `the-apple-core` tag survives the taxonomy scrub; consider a **Ghost collection**
     with its own route (`/the-apple-core/`) in `routes.yaml`
   - set `canonical_url` on republished posts if originals still resolve anywhere
   - backdated bulk inserts: keep them out of RSS/newsletter blasts (Ghost sends
     nothing for posts created via Admin API with past dates by default — verify
     before mass insert)
